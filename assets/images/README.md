# Imagens do projeto

Use esta pasta para armazenar a capa oficial do livro e outras imagens utilizadas no site.

Sugestão de nomes simples e sem espaços, por exemplo:
- capa-manhas-com-jesus.jpg
- livro-cafe.jpg
- marcador-nfc.jpg

Depois de enviar uma imagem para esta pasta, o site poderá referenciá-la pelo caminho `assets/images/nome-do-arquivo.ext`.
