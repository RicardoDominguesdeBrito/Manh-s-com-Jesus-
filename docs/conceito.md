# Conceito do Livro Solidário

## Ideia central

Um mesmo livro pode passar por muitas mãos. O NFC transforma cada exemplar físico em um ponto permanente de entrada para uma corrente solidária digital.

A proposta não é apenas entregar um livro. É permitir que o exemplar continue circulando e que cada novo leitor possa compreender a iniciativa, acompanhar o caminho daquele livro e participar voluntariamente da campanha.

## Jornada do leitor

1. A pessoa recebe o livro.
2. Aproxima o celular da etiqueta NFC.
3. Abre a página do exemplar.
4. Conhece a campanha e entende que aquele livro faz parte de uma corrente.
5. Lê o livro.
6. Futuramente, poderá contribuir voluntariamente com a campanha.
7. Futuramente, poderá registrar que recebeu aquele exemplar.
8. Entrega o livro a outra pessoa.
9. O próximo leitor repete o ciclo usando o mesmo NFC.

## O que a página de cada exemplar deverá mostrar

- número do exemplar;
- status de circulação;
- quantidade de leitores registrados;
- cidades visitadas, quando informadas voluntariamente;
- trajetória do exemplar;
- impacto acumulado da corrente;
- orientação para passar o livro adiante;
- opção futura de contribuição;
- opção futura de registrar o recebimento.

## Princípios

- participação voluntária;
- privacidade dos leitores;
- nenhuma geolocalização automática;
- nenhum dado pessoal obrigatório;
- transparência sobre o que é registrado;
- o livro continua circulando mesmo sem contribuição financeira;
- a doação financeira é uma possibilidade, não uma condição para participar.

## Fase atual

Neste momento, o projeto contém apenas a estrutura estática necessária para demonstrar o conceito. Identidade visual, backend, Pix, domínio e mecanismos de registro serão definidos posteriormente.
